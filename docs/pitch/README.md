# Principal meeting pitch pack

Professional materials for a **30–45 minute** conversation with a school principal (optionally with the exam co-ordinator).

| File | Use |
|---|---|
| [`principal-meeting-presentation.html`](./principal-meeting-presentation.html) | Interactive 8-slide deck for the meeting (open in a browser) |
| [`principal-outreach-email.md`](./principal-outreach-email.md) | Cold outreach + same-day thank-you email drafts |
| [`principal-leave-behind.md`](./principal-leave-behind.md) | One-page summary / pilot checklist to leave or attach |

## How to present

1. Open `principal-meeting-presentation.html` in Chrome or Edge.
2. Press **P** for fullscreen (or use the browser’s fullscreen).
3. Advance with **→**, **Space**, or **Next**; go back with **←**.
4. Print to PDF from the browser if you need a handout version (`Ctrl/Cmd+P` — every slide is a page).

## Suggested meeting flow

| Time | Block |
|---|---|
| 0–8 min | Listen to their current marks process |
| 8–12 min | Pitch (slides 2–5) |
| 12–28 min | Live product demo |
| 28–45 min | Objections, pilot ask (slides 7–8), next steps |

Send the outreach email first. Attach only the leave-behind for cold contact; send the full deck after the meeting with the thank-you note.

## Product one-liner

> We replace exam-week Excel chase with approved mark registers, school-branded reports, and one place for leadership to see what is still missing.
